# 外部簡易2Dマップ

0.3.2以降：本ビューアはパラメーター確認用。visible=falseでも取得したnx/nyを表示する。
modは最終目撃キャッシュを生成しないため、本ビューアも失探履歴を生成しない。
以下の旧最終目撃表示の説明より [OBSERVATIONS.ja.md](OBSERVATIONS.ja.md) を優先する。

modの変更やゲームファイルへの書き込みは不要です。Python 3.10以上とブラウザのみ使用し、追加依存・外部CDNはありません。`launch-map-13357625.bat` をダブルクリックし、終了はコンソールで Ctrl+C。既定では build 13357625 の `res_mods\PnFMods\WowsExtractor` を読みます。戦闘データがない間は待機します。

別の場所やポートを使う例（任意のカレントディレクトリから実行可能）:

```bat
launch-map-13357625.bat --mod-dir "C:\path with spaces\WowsExtractor" --port 8766 --no-browser
```

`--no-browser` 時は表示された `http://127.0.0.1:8766/` を開きます。ポート競合時は別ポートを指定してください。サーバーは127.0.0.1限定、GET/HEADのみ、指定のJSONと同梱HTML以外は公開しません。ローカルの他プロセスからはアクセスできるため、個人情報を含む戦闘データの取り扱いに注意してください。個人名は画面に表示しません。

艦は取得したnx/nyを使い、visible=falseでも表示します。lastNx/lastNyは現行modが生成せず、ビューアも最終目撃履歴を生成しません。自艦もshipsに対応行がある場合に表示します。地図マーカーはvisible=trueでも鮮度未検証で、現在可視の証拠ではありません。魚雷はmapPosition優先、なければ較正係数の逆変換で推定します。範囲外は描かず件数を警告します。較正なしでは変換できません。矢印は連続取得した地図座標の差分方向であり、yawや確定した船首方向ではありません。選択詳細のUI typeとUI isHoming/isSpottedはAPI typeと別で、unknownはfalseではありません。UI供給者はフィールドから確定できません。

state/metaのbattleIdが両方非nullで一致する場合だけ結合します。解析失敗は短時間再試行し、最後の正常データを古いと明記します。ファイル更新が3秒止まった場合も古いと表示し、ゲーム時刻tsをUnix時刻と扱いません。終了フレームでは同じbattleIdの最後の戦闘をinactiveとして保持し、新戦闘とは混ぜません。ブラウザを終了してから起動した場合、以前の戦闘画面は復元しません。

地図の軸・画面上位置、可視/最終目撃判定、別地図や向きの正確性は未検証です。戦術上の確定情報として使用しないでください。

検証：localhost HTTPテスト、非有限数/壊れたJSON・戦闘ID不一致・stale、
JSの戦闘切替/終了/範囲外/unknown処理を確認しました。
さらに架空データを使いChrome headlessで盤面・自艦/敵艦/魚雷が描画されることを確認済み。
