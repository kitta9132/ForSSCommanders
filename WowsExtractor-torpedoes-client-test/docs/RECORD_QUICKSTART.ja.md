# ワンクリック記録・自動連番

build 13357625 では、配布ルートの `record-13357625.bat` をダブルクリックしてください。
ATMあり試験では `record-with-atm-13357625.bat` を使用すると
`with-atm-bNN.jsonl` に自動採番します（ATMの起動確認や有効化は行いません）。
Python 3.10以上が必要です。modの再導入や管理者権限は不要です。

- 戦闘に入る前に起動し、終了後に Ctrl+C で停止します。
- 保存先は配布ルートの `recordings/without-atm-bNN.jsonl` です。
- 既存番号の最大値の次から保存します。既存記録は上書きしません。
- ATMの有効・無効は変更も確認もしません。この起動用ファイルはATMなし試験用です。
- ウィンドウの `Output:` に実際の保存先を表示します。

汎用CLIでも `--output` を省略すると `recordings/run-01.jsonl` から自動採番します。
`--output-dir` と `--prefix` で保存先・接頭辞を指定できます。
従来の `--output` によるファイル名指定も使用可能です。
